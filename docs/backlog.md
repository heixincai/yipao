# v0.1 之后的候选功能

记录用户在访谈中提过或自然引申的未来方向。v0.1 不实现；只有当验证显示某个方向能改善“约成率/周活”时，再单独排期进入下一版。

- 实时“附近跑者地图”：依赖持续/后台定位，先受类目与审核限制。
- 跑步记录与轨迹：把产品从“约伴”扩展为“跑步工具”，与实时方向绑定。
- 跑点热度/人气榜单：帮助新用户选跑点，属于运营增强。
- 系统撮合：填时间/配速后自动配对，替代人工发帖。
- 跑团与长期社群：先有足够个人约跑再考虑。
- 私聊/群聊：先验证帖内动态能否支撑沟通，再决定是否值得做消息基础设施。
- 重复约跑帖：验证有人持续每周发帖后再实现。
- 信用升级（押金/公开评分）：先看爽约记录是否够用。
- 微信好友/群分享裂变：验证用户是否愿意自发传播后再做。
- 城市扩张：首发城市验证通过后，再决定复制方式。
