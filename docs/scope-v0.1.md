# v0.1 功能清单

## 产品定位

给杭州固定跑点的入门跑者结伴跑步的微信小程序：跑者发布约跑帖，附近/常跑点的其他跑者加入，成团 2–5 人后到受管跑点完成一次真实约跑。成功指标：每周至少一次真实约成。

## 用户侧功能

1. **登录与跑者资料**：微信一键登录。资料含昵称+头像、一句话自我介绍、配速档（新手友好/轻松跑/节奏跑等）、常跑点；浏览不需要资料，发帖/加入前必须完成资料。
2. **受管跑点**：平台预置审核过的公共跑点（首发城市先做杭州）；新增跑点需管理员审核。约跑帖只能挂在受管跑点上。
3. **首页/发现**：默认展示“我选择的常跑点”里招募中的约跑帖，可按城市浏览全部；可选的“找离我近的约跑”按钮在用户主动触发时请求一次前台定位并按时距排序，拒绝授权则回到跑点模式，所有功能仍可用。
4. **约跑帖**：发起人选跑点、时间、人数上限（2–5）、里程/强度档位和补充说明；时间和跑点发布后不可修改，说明/人数上限可改并通知；需要改期只能取消重发。
5. **加入与退出**：招募中且未满时先到先得直接加入；开跑前 2 小时前可自由退出，之后退出或未到场记一次爽约；发起人取消帖子时全员无过错。
6. **帖内动态与订阅消息**：跑前沟通发生在约跑帖的评论/更新里；发起人和加入者按需授权一次性订阅消息，接收“有人加入/退出、帖子被更新、被取消”等状态变化。
7. **跑后确认与记录**：发起人结束帖子并勾选到场名单；到场者获得成行记录。成行次数在资料页展示；爽约次数不对公众可见，只在对方发起/加入相关动作时展示。
8. **安全出口**：拉黑某跑者后不再看到对方；举报帖/跑者，举报进入管理员处理。

## 管理员侧功能

- 审核跑点新增申请。
- 处理举报。
- 处理跑后确认申诉（名单有误）。

## 约跑帖状态机

- `招募中` → 发起人关闭/取消、或人数满 → `已关闭/已取消/已满`
- `招募中` → 到达开跑时间后发起人执行“结束并确认到场” → `已完成`
- 参与者状态：已加入、已退出、已到场、爽约、无过错（发起人取消所致）

## v0.1 明确不做

- 实时“附近跑者地图”与后台/持续定位
- 跑步轨迹/配速记录
- 私聊或群聊、交换微信
- 押金、支付、评分
- 跑团功能、路线社区、跑步数据统计
- 手机号绑定、实名认证
